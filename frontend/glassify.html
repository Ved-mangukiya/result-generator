◈ What is Glassmorphism?
▾
A UI design trend using frosted glass effects — blurred backgrounds, semi-transparent surfaces, and layered depth — for a modern, futuristic aesthetic.
◎ How does backdrop-filter work?
▾
The backdrop-filter CSS property applies a graphical effect (like blur) to the area behind an element, creating a translucent panel effect. Use it with a semi-transparent background.
✦ Browser support?
▾
Supported in Chrome, Edge, Safari, and most modern browsers. Firefox requires the layout.css.backdrop-filter.enabled flag in older versions. Always provide a graceful fallback.
⬡ Performance considerations?
▾
Backdrop blur is GPU-accelerated but can be expensive on mobile. Limit blur radius, reduce the number of blurred layers, and prefer will-change: transform to hint the browser.

FAQ & Resources

Frequently asked questions with glass accordion and resource links.

⚡ How do I install Glassify?
▾
Simply copy the CSS tokens and component classes into your project. Glassify is framework-agnostic — works with plain HTML, React, Vue, or any stack. No build step required.
🌐 Which browsers are supported?
▾
All modern browsers: Chrome 76+, Firefox 103+, Safari 14+, and Edge 79+. For Safari on older iOS, a -webkit-backdrop-filter fallback is included automatically.
🎨 Can I customise colours & tokens?
▾
Yes — all colours, blur tiers, radius values, and gradients are controlled via CSS custom properties in the :root block. Change one variable and it cascades to every component instantly.
📦 Is there a React version?
▾
A React component package is in active development and currently in private beta. Join the waitlist via the newsletter to get early access when it ships.
💳 What's the refund policy?
▾
Full refund within 14 days of purchase, no questions asked. After 14 days, unused licence keys can be transferred but not refunded.
