# Result Generator

A free, full-featured result card generation web application built specifically for Indian coaching classes.

Generate premium, print-ready result cards for students across all Indian education boards — CBSE, ICSE, GSEB, MSBSHSE, RBSE and more. Supports all standards from 1st to 12th including all stream combinations for 11th and 12th (Science PCM/PCB, Commerce with/without Maths, Arts).

---

## Features

- Multi-board support with all major Indian boards pre-loaded
- All standards 1st to 12th with correct subject lists per board
- 11th and 12th stream combinations — Science, Commerce, Arts, Vocational
- Fully customisable subjects, max marks, and internal/external marks split
- Manual student entry or bulk Excel/CSV import with smart column mapping
- 6 premium result card templates — all different, all print-ready
- Coaching logo, tagline, address, phone, website on every card
- Student photo support — upload or blank placeholder
- Custom grading system per board with Indian board defaults pre-loaded
- Ranks, percentile, distinction/first class/second class result categories
- Remarks section per student
- PDF export — single student or bulk (entire class, one page each)
- Excel export — all students with marks, grades, totals in clean columns
- A4 Portrait and A4 Landscape support
- Admin dashboard with class-wise pass/fail/distinction stats
